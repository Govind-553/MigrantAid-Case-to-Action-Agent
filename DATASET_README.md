# MigrantAid Synthetic Data

This directory contains the initial synthetic evaluation and resource data.

- `evaluation_cases.json`: 20 synthetic evaluation cases.
- `resources.json`: 6 synthetic resource records.
- `sources.json`: provenance records for those resources.

## Important

These records are **not real government/NGO services** and must not be presented as real-world service information.

Before using real public resources, replace synthetic records with verified data and preserve source/verification metadata.

The evaluation dataset is initially `v1.0` but is **not frozen** until the team has reviewed and approved the ground truth.
